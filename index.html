Cómo subir los Buenos Días

Guía rápida para que la web se actualice sola, sin errores

1 Nombra el archivo con la fecha

El PDF del "Buenos días" se llama solo con la fecha, en formato AAAAMMDD, y termina en .pdf. Nada de títulos, guiones bajos ni texto añadido.

20260916.pdf Ejemplo: el Buenos Días del 16 de septiembre de 2026 se llama 20260916.pdf

2 Súbelo a la carpeta de tu etapa

Cada etapa tiene su propia carpeta de origen. Dentro de la vuestra, entra en Pastoral → BBDD → 0 - Web y deja ahí el PDF. Si tienes dudas de cuál es tu carpeta, pulsa "Abrir carpeta":

  • 👶 InfantilInfantil / Pastoral / BBDD / 0 - WebAbrir carpeta →
  • 🎒 1º-3º EPOEPO / Pastoral / BBDD / 0 - WebAbrir carpeta →
  • 🎒 4º-6º EPOEPO / Pastoral / BBDD / 0 - WebAbrir carpeta →
  • 📖 ESO y BachilleratoESO / Pastoral / BBDD / 0 - WebAbrir carpeta →
  • 🎓 CCFFCCFF / Pastoral / BBDD / 0 - WebAbrir carpeta →

3 A partir de ahí, todo es automático

No hace falta escribir título, descripción, ni pegar ningún enlace en ningún sitio. En cuanto el PDF llega a la carpeta, ocurre esto solo:

1
Se copia automáticamente a la carpeta compartida de Pastoral.Así queda también disponible para el resto del equipo.
2
Se genera un enlace público, para que cualquier familia pueda abrirlo sin cuenta.
3
Se crea (o se actualiza) la fila correspondiente en el listado de datos, con la fecha, la etapa y el enlace.
4
La web se actualiza sola.Puede tardar uno o dos minutos en verse el cambio. Compruébalo en salesianas-pastoral.vercel.app — no hace falta tocar nada más.

🔗 ¿El recurso no es un PDF de SharePoint?

Si lo que queréis compartir es un enlace externo (un vídeo de YouTube, un Drive, otra web...) en vez de un PDF, no hace falta subir ningún archivo: usad este formulario en su lugar.

Solo son obligatorios la fecha y el enlace al recurso — el resto de campos son opcionales. Al enviarlo, se añade solo a la hoja de cálculo y se publica en la web, igual que con los PDF.

💡 Cosas a tener en cuenta

  • Un único PDF por día y por etapa.
  • Si subís un archivo con el mismo nombre otro día (por ejemplo, para corregirlo), sustituye automáticamente al anterior — no hace falta borrar nada antes.
  • Título y descripción son opcionales: el botón para abrir el recurso aparece igualmente aunque no se rellenen. No se pueden añadir ni desde el PDF ni desde ningún paso de la subida — si queréis ponerlos, hay que escribirlos directamente en la hoja de cálculo, en la fila con la fecha y etapa correspondientes.
No renombréis ni movéis las carpetas (ni "0 - Web", ni "BBDD", ni "Pastoral", ni las de cada etapa). El sistema que copia y publica los archivos busca esas rutas exactas — si una carpeta cambia de nombre o de sitio, deja de funcionar hasta que se avise y se corrija.

🛠️ Si os equivocáis

Si subís un PDF con el nombre mal escrito, en la carpeta equivocada, o el archivo incorrecto:

  • Borrad el archivo tanto de vuestra carpeta de origen como de la copia en Pastoral, y volved a subir el correcto con el nombre bien puesto.
  • O, más sencillo: avisad a Mª Ángeles y ella lo revisa y corrige.
Importante: borrar el archivo original no borra la copia de Pastoral automáticamente. Si el error ya se procesó, puede que también haya que corregir a mano la fila del listado de datos — por eso, ante la duda, mejor avisar.
